Gates and measurements

Six can fail a build. Four are read by a person.

Gates

  • Every gold quote still in the corpus
  • Every reported number equals its pin
  • No single question changed verdict
  • Judge cache matches the current prompt
  • Labels travel only to identical text
  • Traceability references still resolve

Measurements

  • Retrieval: hit@5, covered@5, coverage@5, MRR
  • Refusal, judged, with the phrase list beside it
  • RAGAS against DeepEval, same answers
  • Judge against judge, and against the labels

No thresholds anywhere. This metric moves in steps of one record in twelve, so a bar on the average is either “one record” or nothing.

Why it earns its keep

Four things reading the code would not have caught

The fixture described a retriever we had replaced both headlines unchanged, 3 of 12 questions moved

Caught by the live check on its first real run, a day after the retriever changed.

A cache keyed by the question, not by what was judged caught in minutes

A second recording of the same questions handed the first one its verdicts.

Better retrieval, worse grounding hit@5 +0.115, grounding −2 of 12

Only the hand labels see it. Establishing it needed a same-day control on the old retriever.

The change worked; the reason given for it did not neither named question is retrieved
